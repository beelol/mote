# V0-30 verification

Item: With `local_only` true and the think harness set to Claude or Codex, `moted` refuses at
startup with a logged reason.

Section: docs/rfcs/v0.md#8-think-lane-local

## Environment
- Date: 2026-10-08
- Host: owner's Mac, Darwin 25.6.0 (arm64)
- Toolchain: cargo 1.89.0
- Network: none

## Notes
`mote_harness::enforce_local_only` returns an error naming the subscription harness when
local_only is true and the think model classifies as Claude or Codex. `moted` runs this guard at
startup, logs a `startup.refused` event and exits non-zero. Integration test
`refuses_subscription_think_harness_at_startup` pre-writes a config with think=claude-opus-4-8 and
asserts the daemon exits non-zero with the reason in stderr. Unit test
`local_only_refuses_claude_and_codex` covers the guard directly.

## Commands and output

$ cargo test -p mote-harness local_only_refuses_claude_and_codex
