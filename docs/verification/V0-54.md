Section: docs/rfcs/v0.md#16-service

## Environment
- Date: 2026-10-09
- Host: owner's Mac, Darwin 25.6.0 (arm64)
- Toolchain: cargo 1.89.0, Ollama 0.35.0
- Network: local Ollama only

## Notes
`moted status` connects to the control socket and calls the `status` RPC, which reports the
socket path, daemon uptime, the models Ollama currently has loaded (GET /api/ps), and the last
event seq from the log.

## Command and output
```
$ MOTE_HOME=/tmp/mote-status-live ./target/debug/moted &   # start daemon
$ ./target/debug/moted status
socket:        /tmp/mote-status-live/moted.sock
uptime:        1 s
loaded models: qwen3:0.6b
last event:    seq 2
```
