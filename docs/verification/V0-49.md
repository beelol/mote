## Notes
The talk lane records each outbound call as a `model.request` event on the `pipeline` scope with
the model, num_ctx and prompt; the ledger carries the timing. Every event is redacted before
storage (mote-redact), so no secret is ever written. The client's Requests tab reads these
`pipeline` rows. Per the Verify clause, this is checked by grepping the stored rows for the
redaction patterns.

Test `requests_store_redacted_payloads_no_secrets` plants `sk-...` in the turn, runs the talk
lane, and asserts the stored `model.request` payload contains no secret and carries the
`[redacted]` marker.
