Date: 2026-10-10.
Environment: macOS 26.6.2 (25G83), arm64, Rust 1.89.0, Cargo 1.89.0, egui 0.31.0.
Status: verified against the current backlog Verify clause.

The shared test-only observation harness uses the production IPC decoder, application event reducer,
chat rendering path and outgoing event queue.
It never implements a replacement reducer or renderer.
Pointer taps and Enter are actual egui input events.
Tab focuses the existing committed action before its keyboard activation.

All ten unchanged JSON fixtures are streamed at all 1,963 framed byte splits.
Each split and malformed finalization receives taps and Enter at positions measured from the complete
fixture in the real renderer.
The prior action is placed away from these positions and that separation is asserted.
Candidate positions emit no event.
Clicking or pressing Enter on the focused prior action emits exactly this existing contract:

```json
{"thread":"main","event":"refresh","args":{},"surface_seq":19,"node_path":[8]}
```

The daemon regression sends bytes through the production `matrix.candidate` RPC dispatcher.
It exercises every prefix of a Refresh action and a form with a toggle and primary submit action.

No form renderer or approximate form lowering is added.
Candidate form positions come from rendering its declared v0 controls as a separate legal probe.
Those coordinates are verified to be outside the committed action.

All 297 rejected finalizations do the same after delivering the real stored diagnostic event.

and root path `[]`.

After form rejection the prior request still passes real daemon admission.
Rejected candidates preserve source, contracts and config bytes.
