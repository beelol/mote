## Notes
`ContextStore::prune_packs` deletes packs with `created_at < now - PACK_TTL_MS` (30 days). The
store uses a swappable clock. Test `prune_removes_packs_older_than_30_days` records a pack,
advances the controlled clock 31 days, records a fresh pack, prunes, and asserts exactly the old
pack is removed.
