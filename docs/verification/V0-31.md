## Notes
`ContextStore::record` inserts one `packs` row (parts as JSON, token_estimate) and one `ledger`
row referencing it, in the same call. Parts carry a SHA-256 hash and a tiktoken o200k_base token
count in the fixed order charter, profile, memory, working set, turn. Test
`three_turns_write_three_packs_and_three_ledger_rows` records three turns and asserts 3 pack
rows, 3 ledger rows, fixed part order and 64-hex hashes.
