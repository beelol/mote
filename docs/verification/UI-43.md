The ObservationHarness runs the real event decoder, reducer, chat view, preview view and surface
renderer in an egui context.
It uses the production scroll areas and outbound event queue.
Test-only observation records painted bounds, their actual painter clips, control response and hit
rectangles, egui layers and IDs, structural paths, scroll viewport bounds, content extents and offsets.
No alternate layout implementation computes these measurements.

All ten unchanged consumer fixtures run at exactly 800 by 480 and 1280 by 800 in both view methods.
They cover all eleven current Node variants.
The tests assert these results:

- Every measured visible interactive fixture target is at least 48 by 48 logical points.
  The Field, Toggle, Select trigger, both Select options and Action are covered.
- Interactive hit regions on the same layer do not overlap.
  Popup layers remain distinct from the underlying surface.
- Each surface paint command retains a clip contained by the intended outer scroll clip.
  The visible paint intersection and control hits remain inside the viewport's screen.
- Repeated frames preserve structural reading order and exact displayed bounds.
  Composed Stack and Row controls also preserve visual reading order.
- A 200-item List and a 500-row Table reach their final rows in all eight viewport/view combinations.
  The final row is fully visible and collection reading order remains stable after scrolling.

The tests exposed undersized real hit regions and the off-screen chat composer before the fixes.
The renderer now extends interaction into reserved padding without enlarging surface visuals.
The chat scroll reserves space for its composer.
The existing outer scrolling already provided collection reachability.
No nested collection region or source-level layout declaration was introduced.

One old isolation helper assumed that a single Tab always focuses the prior Action.
When a diagnostic makes the chat overflow, egui also exposes the scroll region to focus.
The helper now traverses real Tab input until the observed Action ID has focus.
Every intermediate step must preserve exact displayed bounds and emit no event.
The daemon regression still passes 173 Matrix prefixes, 297 rejected finalizations and 48 switches.
No decoder, admission or structural identity assertion was weakened.
