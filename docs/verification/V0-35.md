## Notes
`mem::forget` sets `superseded_by` (and `valid_to`); nothing is deleted. `retrieve` filters
`superseded_by IS NULL`, so a forgotten node is omitted from the next pack's memory part (the talk
lane builds the memory part from `memory_retrieve`). Test `forgetting_omits_from_retrieval` writes
a node, confirms retrieval finds it, forgets it, and confirms retrieval omits it.
