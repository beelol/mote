## Notes
`CharterWatcher` watches the character file with notify (FSEvents), re-parses on change, updates
the shared `Charter` and appends a `charter.changed` event. Lanes read the shared charter prose
when building the next pack, so the new text appears in it. Test
`editing_charter_emits_changed_and_updates_prose` edits the file, waits for `charter.changed`,
and asserts the shared prose updated to the new text.
