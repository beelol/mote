## Notes
`render::render_png` lays a surface tree out as colored blocks (one color per node type, bars
sized by label length, stack/list/chat vertical, row horizontal, table as a grid block) and
encodes a deterministic PNG. The golden PNGs are committed next to each fixture
(`crates/mote-ui/fixtures/NN_*.png`), regenerated with `cargo run -p mote-ui --example
gen_goldens`. Test `fixtures_render_to_matching_golden_pngs` renders all ten fixtures and asserts
byte-exact equality with their goldens. This test renderer is distinct from the on-screen egui
renderer in mote-client; it exists so goldens are reproducible without a GPU or display.
