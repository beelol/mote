Status: partial. Do not check P2-06 yet.

Environment: macOS Darwin 25.6.0 arm64, rustc 1.89.0, cargo 1.89.0.

Implemented in this increment:

- an injectable native `LocalStepClient` boundary with no retained adapter session state;
- a fixed system prompt and generated strict JSON schema for the shared `ModelStep` contract;
- fail-closed parsing for malformed JSON, extra fields, empty or padded strings and unknown tools;
- an explicit tool allowlist and error mapping for timeout, unavailable and malformed local output;
- deterministic prompts containing the durable task request and exact supplied bounded context.
- a production-shaped daemon client that permits only `qwen3-coder:30b-64k` with a 65,536-token
  context, checks the supplied schema, applies the configured model gate and uses structured
  Ollama output;
- redaction before the request event, model transport, context pack and ledger;
- exactly one context pack and one ledger row for successful, malformed, timed-out, unavailable
  and gate-refused attempts;
- an atomic pack-and-ledger transaction that rolls the pack back when the ledger insert fails.
- an opt-in daemon route that constructs the native adapter on the shared database and runs each
  selected owner turn through the durable driver for at most 16 steps;
- durable completion, input, blocked and held-approval outcomes, with every proposed tool held by
  a refusing executor until the production approval reconciliation path exists;
- Matrix and direct configuration journeys that select the Mote harness while absent configuration
  continues to select OpenCode.
