## Contract and coverage

`matrix.candidate` requires `thread`, `candidate`, byte-array `chunk` and boolean `finish`.
State belongs to the `(thread, candidate)` pair.
Non-final requests return `incomplete`, `complete` or `rejected`.
None of those requests appends an event or changes retained source.
A complete parse is provisional until `finish` is true.

`CandidateStream::finalize` consumes the accumulator.
It returns the same AST as whole-source parsing or structured diagnostics.
Incomplete UTF-8 becomes an invalid-character diagnostic at finish.
An earlier rejection remains latched through subsequent chunks and finalization.

Finalization removes terminal candidate state.
Only a complete, resolved and lowered candidate returns `committed` and emits one `ui.surface`.
The existing source lock protects compilation, commitment and retained source replacement.
Canonical source is retained after successful commitment.
Resolution and lowering use the original AST spans.
Whole-source `matrix.render` retains its existing response, event and source behavior.

The parser corpus covers every byte split of the documented examples, recipes and nine v0 fixtures.
Its finalized AST equals the result of complete parsing.
The production corpus also includes the trusted dashboard and explicit UTF-8 and escape cases.
Every prefix is classified against whole-source parsing before the remainder is supplied.
The complete provisional result still leaves the event log and retained source unchanged.
Final results agree with whole-source host compilation.
Syntax-positive fixtures with unavailable host bindings or unsupported v0 semantics reject at finish.

Separate cases cover a complete valid prefix with an invalid tail, unfinished strings and braces,
unfinished UTF-8, latched syntax and source-size rejection, missing host bindings and unsupported lowering.
The source-size case accepts 262,144 buffered bytes and rejects byte 262,145.
Each failure preserves the exact prior source and emits no replacement surface.
A later Refresh emits the exact prior surface payload.
Interleaved candidate ids and equal ids on different threads remain independent.
Terminal ids can start new candidates.
Invalid bytes, fractional numbers, non-array chunks and missing or mistyped parameters return `invalid_params`.
Parameter rejection leaves an existing partial candidate intact.
