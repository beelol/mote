# V0-06 verification

Item: Retention keeps 5,000 events per scope behind one retention marker, and no cursor moves
backwards after pruning.

Section: docs/rfcs/v0.md#2-event-log

## Environment
- Date: 2026-10-08
- Host: owner's Mac, Darwin 25.6.0 (arm64)
- Toolchain: cargo 1.89.0
- Network: none

## Notes
`enforce_retention` trims the oldest real events to exactly RETENTION_LIMIT (5,000) and keeps
exactly one `retention` marker as the oldest surviving row. Because `seq` is AUTOINCREMENT and
only rows below the marker are deleted, a cursor value never moves backwards and pruned seqs
are simply never replayed.
Test `retention_keeps_5000_behind_one_marker` appends 12,000 events to one scope and asserts
count == 5,000, exactly one marker, and marker seq < min real seq.
