# V0-36 verification

Item: `moted bench memory` reports write and retrieve p50 and p95 at 10k and 100k nodes.

Section: docs/rfcs/v0.md#10-memory-graph

## Environment
- Date: 2026-10-09
- Host: owner's Mac, Darwin 25.6.0 (arm64), 128 GB RAM
- Toolchain: cargo 1.89.0
- Network: none (local store; bench uses the deterministic local embedder for speed)

## Notes
`moted bench memory` runs the scale bench at 10k and 100k nodes and appends one JSON line per
scale to `bench.jsonl`, each with retrieve p50/p95 and write p50/p95.

## Result
- 10k nodes:  retrieve p50 11.97 ms, p95 12.71 ms;  write p50 0.042 ms, p95 0.108 ms
- 100k nodes: retrieve p50 130.26 ms, p95 136.85 ms; write p50 0.042 ms, p95 0.105 ms

(V0-36 is a reporting criterion and states no threshold; the 40 ms budget applies at 10k per
V0-34, which this confirms. Retrieve grows to ~130 ms at 100k, recorded here.)
