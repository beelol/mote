## Notes
`run_turn` spawns the router in parallel with the talk lane and hands off on a `think` verdict.
`route` parses the verdict fail-closed: trailing text, unknown field, missing field, prose, wrong
type and an invalid route value all route to `think`. Test
`router_fail_closed_on_six_malformed_verdicts` feeds six malformed verdicts (all -> think) and one
valid talk verdict (-> talk).
