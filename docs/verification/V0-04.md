# V0-04 verification

Item: Appending an event returns a strictly increasing `seq` and stores already-redacted JSON.

Section: docs/rfcs/v0.md#2-event-log

## Environment
- Date: 2026-10-08
- Host: owner's Mac, Darwin 25.6.0 (arm64)
- Toolchain: cargo 1.89.0
- Network: none

## Notes
`EventLog::append` redacts the payload text through `mote_redact::redact` before the INSERT.
Test `append_is_strictly_increasing_and_redacts` appends 1,000 events asserting each `seq`
strictly exceeds the last, then appends a payload containing `sk-...` and asserts the stored
and replayed payload reads `[redacted]`.
