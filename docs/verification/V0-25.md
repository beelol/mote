## How it was reached
Initial prompt scored 0.333 (routed everything to talk). The score crossed the gate after:
- a deterministic greedy decode (temperature 0) with chain-of-thought disabled (keeps the V0-26
  150 ms budget);
- a decision-rule prompt framed around lane capability: the talk lane is a tiny model with no
  tools or memory, so any request to read, list, search, summarise, recall or look anything up,
  anything mentioning a file/notes/emails/the past, and any factual question must route to think;
  only greetings, thanks and small talk are talk.

This is general capability-based prompt engineering, not overfitting to the 60 turns. The router
latency gate (V0-26) is unaffected. The 60 labelled turns live in `mote_testkit::ROUTER_TURNS`
(30 talk, 30 think).
