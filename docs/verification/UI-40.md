# UI-40: surface arrival to first production render

Date: 2026-10-10.

Status: partial. Native daemon round trips and the measured CPU render boundary pass below 50 ms.
GPU and compositor presentation timing remains outside the instrumented boundary, so the literal
arrival-to-display clause remains open.

## Measured boundary

The client uses one monotonic `Instant` origin for the IPC stream thread and the egui application.
It timestamps a complete decoded IPC event immediately after `EventStream::read_event` returns and
before the event is queued. A successful queue send requests an immediate egui repaint. The existing
100 ms repaint timer remains as an idle fallback.

An exact `ui.surface` receives a private render revision only after tree validation, replay watermark
checking and chat reduction accept it. The production Chat draw path reports revisions after their
surface tree traverses `surface::draw`. The sample ends immediately after `draw_shell` returns.

This measures complete decoded IPC frame through first egui render-list construction. It includes
queueing, validation, reduction and CPU render work. It does not measure GPU or compositor
presentation.

## Automated coverage

The deterministic manual-clock test receives an accepted Matrix surface at 100 ms and its replacement
at 105 ms. It also receives an invalid surface and a valid surface below the replay watermark. A
Pipeline frame at 111 ms records nothing. The first Chat frame at 112 ms records one 7 ms sample for
the replacement. A later Chat frame records nothing. The superseded, rejected and stale surfaces
record no sample. The stream test proves an invalid decoded frame is not delivered and does not clear
the committed surface.

The stream tests pin decoded-event timestamp propagation and require repaint only after successful
queue delivery. The summary test uses 20 explicit durations. Nearest-rank p50 is the tenth value and
p95 is the nineteenth value.

When `MOTE_UI_LATENCY_REPORT` names a path, clean client shutdown writes one JSON object. The report
contains the sample count, nearest-rank p50 and p95 in nanoseconds and milliseconds, the declared
boundary, and per-sample sequence and monotonic timing fields. It contains no payload or source.

## Native live acceptance

Date: 2026-10-10.

Environment: owner's Mac, macOS 26.6.2 (25G83), arm64, Rust 1.89.0 and Cargo 1.89.0. Release
`moted` and `mote-client` ran with the isolated data root
`/private/tmp/mote-live-evidence.UvExgw`. The client submitted the checked-in
`matrix/examples/mote-dashboard.matrix` source. No chat turn was sent.

The live command flow was:

```text
cargo build --release -p moted -p mote-client
MOTE_HOME=/private/tmp/mote-live-evidence.UvExgw ./target/release/moted
MOTE_HOME=/private/tmp/mote-live-evidence.UvExgw \
  MOTE_UI_LATENCY_REPORT=/private/tmp/mote-live-evidence.UvExgw/ui-latency-40.json \
  ./target/release/mote-client --matrix matrix/examples/mote-dashboard.matrix
MOTE_HOME=/private/tmp/mote-live-evidence.UvExgw ./target/release/mote-client
```

The first native session displayed the committed dashboard inline. It produced 20 successful,
visible Refresh actions. The event log stored exactly 20 `ui.event` rows with event `refresh` at
sequences 2 through 40, followed by 20 refreshed surfaces. Together with the initial submitted
surface, this yielded 21 `ui.surface` rows at sequences 1 through 41. The client cursor reached 41.
The client closed normally.

The client then reopened without `--matrix`, using the same `MOTE_HOME`. The cursor remained 41 and
the database remained at 41 events with 21 surfaces. The reopened screenshot shows an empty chat and
no duplicate dashboard. Client chat state is in memory only, so this confirms replay starts after
the saved cursor; it does not claim chat-history restoration. The native screenshots are
[the initial dashboard](assets/UI-40-native-dashboard.png) and
[the reopened client](assets/V0-43-native-reopened-no-duplicate.png).

A subsequent latency run resubmitted the same dashboard and performed 40 successful, visible
Refresh round trips. Across the initial and latency sessions, the isolated log held 60 `refresh`
`ui.event` rows and 62 `ui.surface` rows. The final cursor and maximum event sequence were 122. The
ledger and packs tables both had zero rows. The latency run therefore measured native IPC surface
delivery and rendering without a model turn.
