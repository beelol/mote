# UI-29 typed activation envelope

Date: 2026-10-10.

Implementation commits: `26af560`, `7feca92`, `75e3f8d`, `4d97573`, `029d79f` and `6e1ac31`.

Environment: macOS 26.6.2 (25G83), arm64, Rust 1.89.0, Cargo 1.89.0.

Status: partial. The criterion remains open.

The immediate-mode renderer emits actions and control edits in the existing `event` and `args`
envelope. Boolean toggles and string selects emit only when their value changes. The daemon accepts
only the four fields in its trusted Matrix manifest, checks model values against the three approved
local models, rejects wrong types and unknown fields, and does not store rejected changes. One
ordered background worker keeps the window responsive and preserves click order. A failed call
shows its error and restores the last committed host value.

The client tests, daemon dispatch tests, workspace tests and workspace clippy passed. A live native
run recorded `{"event":"change","args":{"field":"models.local_only","value":false}}`, then
restored the isolated value to true.

The full criterion still needs host revision and node context in the contract, stale-revision
rejection, missing action-argument coverage and a general activation path beyond this v0 field and
zero-argument action slice.
