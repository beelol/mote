## Notes
`ensure_with_free` lists models via /api/tags, returns `Missing` when the model is absent, runs
the memory gate, then loads by a minimal /api/chat and returns the elapsed load time. It never
posts /api/pull. Test `ensure_missing_memory_gate_and_load_time` covers the missing case, the
gate case (500 GB model, 8 GB free), the success case (returns a non-zero duration), and asserts
no /api/pull request was recorded.
