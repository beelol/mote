The full criterion remains open.
The internal host snapshot input distinguishes ready, pending and failed proposals.
Only ready values can enter the current `BindingSnapshot` and commitment path.
The v0 consumer has no lossless representation for pending, failure, key or selection semantics.
Proposal rejection is verified here, but visible pending and failure transitions and keyed or
selected behavior require the separately approved revised consumer contract.
