Status: partial. Common state-transition fixtures are still required.

Environment: local macOS workspace, Rust 2021. Date: 2026-10-18.

Added `crates/mote-hrns` with task, action, checkpoint, scoped identity, model-step and harness
types. The crate depends only on serde and serde_json. It does not run models or tools.

`cargo test -p mote-hrns --test contracts` first failed because the package did not exist.
After implementation it passed: 4 passed, 0 failed.

`cargo test --workspace` passed with exit 0. Explicit live tests remained ignored.
`cargo clippy --workspace -- -D warnings` passed with exit 0.
`cargo fmt -p mote-hrns -- --check` and `git diff --check` passed.

The tests cover nonempty identities through constructors and deserialization, every task and
action state, model-step round trips, rejection of unknown or missing step fields and non-object
tool arguments, and both harness selections using the same request contract. Checkpoints reject
adapter session fields.

This proves the initial data boundary only. It does not prove transitions, persistence, approval
enforcement, harness integration or restart recovery. The root criterion remains unchecked.
