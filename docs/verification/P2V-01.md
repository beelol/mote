# P2V-01 product-neutral voice protocol

Status: complete.

Date: 2026-10-18.

Environment: macOS Darwin 25.6.0 arm64, rustc 1.89.0, cargo 1.89.0.

The `mote-voice-protocol` crate defines the bounded JSON Lines boundary shared by a local voice
listener and an agent runtime. Its wire shapes are derived from Overseer revision
`2b1a19a9b6e639628367a22e16155af20df4f86a`, with the product source label replaced by `agent`.
The crate source contains no Mote or Overseer runtime name. Its README and NOTICE record the
source revision and license provenance.

Every command and event has a checked-in golden frame. Decoding rejects unknown fields, malformed
JSON, blank frames, multiple frames and frames larger than one mebibyte. Production decoding
refuses `feed`, `feed_end`, `simulate` and `script`; those commands are accepted only under an
explicit fixture input mode. Events have no audio field, so production output carries only state,
text and bounded metadata.
