# P2V-06 verification

Date: 2026-10-20

Environment: macOS, local Rust workspace, isolated loopback scripted Ollama server. Live microphone
and physical iPad input were not used.

## Clause

Final utterances enter `mote-hrns` once as scoped owner turns while partial words and levels never
invoke a harness. Duplicate finals and listener reconnects must produce one durable task and one
ledgered model step.

## Result

Passed. Each explicit owner start records a durable voice session ID. Automatic listener restarts
retain that session. The supervisor accepts only complete utterances, deduplicates their listener
IDs within the session and hands them to a separate bounded worker. The worker uses the
`owner/personal` scope and the durable Mote HRNS driver. Its deterministic task identity makes a
second delivery a no-op before another model step.
