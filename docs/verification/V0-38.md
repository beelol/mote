## Notes
`charter::check_tool` returns Ok for a listed tool and, for an unlisted one, appends a
`tool.refused` event naming the tool and character and returns an error. The daemon exposes this
as `tools.allowed`. Test `unlisted_tool_is_refused_and_logged` allows `memory_search`, refuses
`shell_exec`, and confirms the refusal event was logged.
