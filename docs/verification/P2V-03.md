# P2V-03 optional macOS voice runtime

Status: complete.

Date: 2026-10-19

Environment: Apple Silicon macOS, Rust 1.89 workspace on `main`. Network access was not used by
the crate or its tests. Microphone permission and a live audio device were not required for the
deterministic fixture suite.

## Verified behavior

`mote-voice-macos` provides a product-neutral macOS runtime with voice-processing audio-unit
capture and playback, CoreAudio call detection, target-gated local Whisper 0.16 Metal recognition,
in-memory system speech and a deterministic phrase buffer. Start, stop, pause and resume failures
clean up or roll back without leaving the runtime in a false state. The output queue remains the
same shared buffer before and after microphone start.

Non-macOS builds keep the portable traits and deterministic fakes while returning an explicit
unavailable error for real platform I/O. The crate has no daemon, task, product, network,
subprocess, temporary-file or persisted-audio dependency.

The implementation records its exact source revision and derived files in the crate README and
NOTICE: `beelol/overseer@2b1a19a9b6e639628367a22e16155af20df4f86a`.

## Limits

P2V-03 proves the reusable platform layer, not the listener or daemon-to-app voice journey. The
30-second held-audio bound, 90-second utterance cap, process supervision, permission UX, task
routing and Matrix state remain P2V-04 through P2V-08.
