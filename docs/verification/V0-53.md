# V0-53 verification

Item: `moted install` loads the launchd agent, the daemon survives logout and login, and `moted
uninstall` removes it.

Section: docs/rfcs/v0.md#16-service

## Status: OPEN (install is a deploy; logout/login survival needs the owner's session)

## Environment
- Date: 2026-10-09
- Host: owner's Mac, Darwin 25.6.0 (arm64)
- Toolchain: cargo 1.89.0

## What is implemented
`moted install` writes `~/Library/LaunchAgents/com.mote.moted.plist` (KeepAlive, RunAtLoad,
StandardOut/ErrPath under the data directory, MOTE_HOME env) and runs `launchctl load -w`.
`moted uninstall` runs `launchctl unload -w` and removes the plist. The plist generation is unit
tested (`plist_has_label_keepalive_and_log_paths`).

## Why it is left open
Loading a LaunchAgent is a deploy that changes the owner's login environment, and "survives
logout and login" can only be checked by an actual logout/login. The driver does not perform
deploys. The owner runs:
```
moted install
launchctl print gui/$(id -u)/com.mote.moted    # capture into this evidence file
# log out and back in, confirm moted is running (moted status)
moted uninstall
```
and records the `launchctl print` output here.
