# P2V-04 bounded voice listener

Status: complete.

Date: 2026-10-19

Environment: Apple Silicon macOS, Rust 1.89 workspace on `main`. The live descriptor inspection
used the fixture input so it required neither microphone permission nor a Whisper model.

## Verified behavior

`mote-voice-listener` accepts explicit `mic` or `fixture` input and communicates with its parent
only through newline-delimited JSON on standard input and output. Ordinary microphone mode rejects
fixture-only PCM, simulation and scripted-recognition commands. Events contain bounded text and
metadata but never PCM.

The listener incrementally recognizes long input while retaining at most 30 seconds of audio and
terminates an utterance at 90 seconds. Malformed commands fail closed without terminating the
listener. The microphone path uses only the local macOS runtime and local Whisper model.

## Limits

P2V-04 proves the bounded listener process and its absence of outbound sockets. It does not prove
daemon supervision, owner permission flow, final-utterance task routing, speech interruption or
the complete app journey. Those remain P2V-05 through P2V-08.
