# V0-28 verification

Item: `moted mcp` serves the four tools over stdio and a think turn calls `memory_search`
through it.

Section: docs/rfcs/v0.md#8-think-lane-local

## Environment
- Date: 2026-10-08
- Host: owner's Mac, Darwin 25.6.0 (arm64)
- Toolchain: cargo 1.89.0
- Network: none (fake harness drives the server in-process)

## Notes
`McpServer` answers JSON-RPC `initialize`, `tools/list` and `tools/call` for `memory_search`,
`memory_write`, `file_read` and `file_list`, and `serve` runs it over stdio for `moted mcp`.
The fake harness (`mote_testkit::FakeHarness`) performs the handshake and a `tools/call`. Test
`think_turn_calls_memory_search_through_mcp` writes a memory, then the fake harness calls
`memory_search` and the result contains the stored text. `unknown_tool_is_an_error` covers the
error path.

## Commands and output
```
$ cargo test -p moted mcp::
test mcp::tests::think_turn_calls_memory_search_through_mcp ... ok
test mcp::tests::unknown_tool_is_an_error ... ok
test result: ok. passed
```

## Follow-up: standalone `moted mcp` subprocess

The original V0-28 test drives the server in-process. Running `moted mcp` as a real subprocess
(as OpenCode spawns it) revealed it failed to open the context store when the data directory did
not yet exist. Fixed by ensuring the data directory in `run_mcp`. Confirmed live:
```
$ printf '%s\n%s\n' '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{}}' \
    '{"jsonrpc":"2.0","id":2,"method":"tools/list"}' | moted mcp
INIT ok
TOOLS: ['memory_search', 'memory_write', 'file_read', 'file_list']
```
