## Notes
`tree_schema` derives the JSON schema from the `Node` type via schemars. The committed
`schemas/tree.v0.json` is produced by `cargo run -p mote-ui --example gen_schema`. Test
`schema_file_matches_generated` compares the committed file to the freshly generated schema and
fails on any drift.
