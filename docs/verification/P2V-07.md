## Clause

Speaking, barge-in and interruption preserve the played-word boundary in context and do not
bypass an outstanding approval.

## Result

Passed. Completed durable tasks queue numbered speech lines through the supervised listener. The
listener uses the shared macOS in-memory speech queue, emits phrase progress, lowers and restores
playback during possible barge-in and supports immediate and phrase-boundary stops. Stop phrases
interrupt playback but are dropped before task routing. A normal barge-in remains an owner turn.

Mote persists `SpokenLine` progress using a count of fully completed words. An interruption inside
a phrase retains only earlier completed phrases. The next voice task context contains that retained
prefix and cannot contain unplayed suffix text. If another task has an outstanding approval, the
new voice task remains queued and no second model step or action is attempted.
