## Contract and limits

The sample uses the committed `matrix/examples/mote-dashboard.matrix` source.
It uses all nine v0 config defaults and an empty pipeline numbers snapshot.
Request id is 1, thread is `main`, event sequence is 1 and event timestamp is normalized to 0.
These are deterministic measurement sample values.
The utility invokes the production pipeline builder, host bindings, compiler, v0 validator and
redacting event log without changing their behavior.

The manifest and snapshot counts use the separately declared canonical encodings in the report.
Neither structure is transmitted during this render.
The counts are not serialized production bytes or memory sizes.
The request, response and subscribed event use the current real IPC envelope shapes.
Their measured JSON lines include newline framing.
The envelopes are deterministic samples encoded by shared production builders.
The client and server use the same request, success and event builders and frame encoder.
The daemon and measurement use the same Matrix success result and surface payload builders.
No live traffic capture is claimed.
The request transports escaped source; the response transports success and validity; the event
transports the compiled tree and surface identity.
The compiled JSON row is contained in the event row.
The three IPC rows total 1353 bytes for this sample.
Source syntax savings do not establish total transport savings.
Populated data, timestamp widths, subscriptions, other events and socket overhead are excluded.

## Production drift regression

Review found that the original independently constructed envelopes could miss a production change.
Before the fix, adding `transport_probe=true` to the daemon's successful render result left the
measurement check green.
A test expecting this production drift to fail the check therefore failed with exit 1 and:

```text
FAIL: production result changed but the measurement check passed
```

After extracting shared builders, `sh matrix/tools/measure.sh --check` failed with exit 1 for each
of six independently applied and restored production mutations:

| Production mutation | Changed measured row | Bytes | Tokens |
|---|---|---|---|
| Add probe to daemon result | `matrix_render_response` | 66 | 20 |
| Add probe to daemon payload | `ui_surface_event` | 797 | 262 |
| Add probe to request envelope | `matrix_render_request` | 559 | 136 |
| Add probe to success envelope | `matrix_render_response` | 66 | 20 |
| Add probe to event envelope | `ui_surface_event` | 797 | 263 |
| Add space before frame newline | request / response / event | 537 / 44 / 775 | 131 / 16 / 259 |

The unmodified shared production output passed two checked runs afterward.
Both runs retained the original complete output SHA-256 recorded above.
The fixture was not changed to accommodate the refactor.
