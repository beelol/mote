The production end-to-end compiler p95 was 0.039458 ms. This is strictly below the 2.0 ms
Apple Silicon limit. The command used 200 untimed warmups and 2,000 interleaved samples. It used
nearest-rank p95. The fixed in-memory fixture contains the checked-in dashboard source, all nine v0
config defaults, five pipeline rows, host progress 0.5 and host items `first` and `second`.

The criterion remains partial. The same release benchmark has not run on actual Raspberry Pi 5
hardware. Linux arm64 alone does not activate the Pi 5 budget. The benchmark requires the hardware
model to identify Raspberry Pi 5 before it applies the strict 10.0 ms limit.

The byte and token measurements in `matrix/measurement.md` are unchanged. They are not compiler
latency evidence.
