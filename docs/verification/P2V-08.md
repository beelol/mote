# P2V-08 voice surface

Status: partial. Do not check P2V-08 yet.

Date: 2026-10-19.

Environment: macOS Darwin 25.6.0 arm64, rustc 1.89.0, cargo 1.89.0.

This increment adds a reusable immediate-egui circling avatar for off, starting, listening,
hearing, thinking, speaking, paused, unavailable and error states. Animation is deterministic from
explicit elapsed time. Reduced motion produces a static ring treatment. The avatar exposes a
distinct accessible status value and a start or stop control with at least a 48-point hit target.

The offline iPad gallery has a selectable Voice page that previews every state and clearly says it
does not capture audio. The normal paired-host shell shows a compact voice control by default above
the existing typed chat. Its app-owned state starts off. Until the voice supervisor exists, Start
changes to a truthful unavailable state, Stop returns to off and typed chat stays present.
