## Implemented boundary

`matrix/examples/voice-status.matrix` is the default voice status surface. It binds only four
redacted strings: the accessible state label, detail or error, partial words and the current
speaking line. Each visible status string is capped at 512 Unicode scalar values after redaction.
The surface exposes one `voice_toggle` action and contains no audio bytes or model path.

The daemon carries those values in durable `voice.state` events and in Matrix host bindings. The
immediate Rust renderer draws the Matrix header, text and control, with the existing deterministic
circling avatar directly below the surface. The paired iPad protocol accepts the same strict status
payload and displays partial and speaking text for the selected host. Typed chat remains available
for every state.
