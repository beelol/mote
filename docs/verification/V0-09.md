## Notes
Mapping: malformed JSON -> `parse_error`; a frame over MAX_REQUEST (1 MiB) -> `invalid_request`
("request exceeds 1 MiB"); a well-formed request naming an unknown method -> `invalid_request`
("unknown method: ..."). The error reply shape is `{"id","error":{"code","message"}}`.
Test `error_codes_for_bad_requests` sends each case and asserts the code.
