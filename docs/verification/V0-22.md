# V0-22 verification

Item: When the talk model cannot load, the lane emits `talk.unavailable` with the reason and
uses no other model.

Section: docs/rfcs/v0.md#6-talk-lane

## Environment
- Date: 2026-10-08
- Host: owner's Mac, Darwin 25.6.0 (arm64)
- Toolchain: cargo 1.89.0
- Network: none (scripted Ollama server returns 404)

## Notes
When `chat_stream` fails, `run_talk` emits `talk.unavailable` with the error reason and returns
without calling any other model. Test `talk_unavailable_when_model_cannot_load` sets the scripted
server to 404, asserts the `talk.unavailable` event (reason contains 404), asserts no `talk.done`,
and asserts every `/api/chat` request used only the talk model.
