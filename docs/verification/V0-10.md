# V0-10 verification

Item: A peer with a different uid is refused before any request is read.

Section: docs/rfcs/v0.md#3-ipc

## Environment
- Date: 2026-10-08
- Host: owner's Mac, Darwin 25.6.0 (arm64)
- Toolchain: cargo 1.89.0
- Network: none

## Notes
`peer_uid` reads the connected peer's uid with `getpeereid`. The accept loop calls
`peer_allowed(fd, our_uid)` and, on mismatch, shuts the connection down before any frame is
read. Test `peer_credential_check` asserts `peer_uid` of a connected pair equals our uid,
`peer_allowed` is true for our uid, and false for a different uid.
