Implemented in this increment:

- bounded coding-task submission in Overseer worktree mode;
- opaque task and run identities with strictly increasing event cursors;
- normalized progress, permission, completion and failure events;
- permission answers routed back through Overseer;
- explicit unavailable and invalid-payload failures;
- no worktree or Mote action-commit authority in the delegate contract.
- the exact pinned Overseer socket discovery layout, including its long-path fallback;
- an owner-UID-checked protocol-v1 hello and bounded one-megabyte JSONL frames;
- strict unary submission, event replay and permission calls with monotonic cursor, truncation,
  resync and replay-limit refusal;
- a concrete transport that normalizes the pinned socket protocol behind the existing delegate
  contract.
