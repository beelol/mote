# V0-08 verification

Item: `moted` listens on the socket with mode 0600 and a second `moted` exits non-zero naming
the socket path.

Section: docs/rfcs/v0.md#3-ipc

## Environment
- Date: 2026-10-08
- Host: owner's Mac, Darwin 25.6.0 (arm64)
- Toolchain: cargo 1.89.0
- Network: none

## Notes
`Server::bind` connects to an existing socket to detect a live owner and, if present, returns
`AddrInUse` naming the path; otherwise it binds and sets mode 0600. `moted` prints the error to
stderr and exits 1. The integration test `second_instance_exits_naming_socket` spawns one
daemon under a temp `MOTE_HOME`, asserts the socket mode is 0600, spawns a second, and asserts
it exits non-zero with the socket path in stderr. The library test
`socket_mode_is_0600_and_second_bind_fails` covers the same at the crate level.
