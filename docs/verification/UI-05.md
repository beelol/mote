The node boundary is one screen plus one list plus 999 copies of item and text.
Its count is `2 + 999 * 2 = 2,000`.
One final divider makes 2,001 and reports `E_RESOLVE_LIMIT` at `screen/1`.

Retained bytes preserve the existing resolver accounting.
Each declaration costs 16 bytes.
Retained values cost the greater of their compact raw JSON size and compact display JSON size.
Retained type names, formatter symbols, identities, argument names and properties retain their existing charges.
The budget is not a measurement of the Rust heap footprint.
Temporary collection source lists and selection values are not newly charged.

A screen and one text with 262,110 ASCII characters cost `32 + 262,110 + 2 = 262,144`.
One extra character makes 262,145.
The expanded fixture has six declarations and two strings of 131,022 characters.
Its cost is `6 * 16 + 2 * (131,022 + 2) = 262,144`.
One extra character in the second row makes 262,145.
The transient record list is smaller than its own individual bound and is not charged again.

The formatter test accepts an enum label containing 131,054 quote characters and one ASCII character.
Its retained cost is `32 + 1 + 2 * 131,054 + 1 + 2 = 262,144`.
The next ASCII character exceeds the limit.
The money test uses a 131,054-byte symbol and integer 10.
Its cost is `32 + 131,054 + 131,054 + 2 + 2 = 262,144`.
Integer 100 increases that cost by one.

The compact field JSON has 64 bytes of fixed syntax, keys and metadata.
The lowerer accepts 262,080 encoded value-content bytes and rejects 262,081.
Both plain strings and escaped quote strings are tested.
These compact JSON fixtures still resolve successfully before lowering.

## Allocation order

Six real resolver allocation probes count only allocations of the fixture's sentinel size on the current test thread.
They observe the system allocator and do not replace resolver behavior.
All fixture creation and parsing finish before counting starts.

| Retained allocation | Observed RED | Required GREEN |
| --- | --- | --- |
| Bound raw and display strings | 4 copies | 2 copies for the accepted first value |
| Bound list argument string | 2 copies | 1 copy for the accepted first argument |
| Declaration property string | 2 copies | 1 copy for the accepted first property |
| Literal raw and display strings | 4 copies | 2 copies for the accepted first value |
| Literal stages list string | 3 copies | 1 copy for the accepted first list |
| Formatter symbol | 4 allocations | 1 retained symbol copy |

The resolver measures escaped JSON through counting writers before copying retained values.
It borrows manifest bindings and existing display text during measurement.
Money prefix and numeric text are measured separately with the duplicate JSON quotes removed.
The combined display buffer is allocated only after its charge succeeds.
Numeric formatting uses bounded temporary scalar text.
Literal lists are measured through borrowed string slices before their owned values are created.
Static declaration property sizes are charged before property cloning.
The late value and property charges are removed, so accepted content is not charged twice.
Node admission and collection count checks remain ahead of retained declaration construction.
