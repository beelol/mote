# P2V-02 portable voice decisions

Status: complete.

Date: 2026-10-19.

Environment: macOS Darwin 25.6.0 arm64, rustc 1.89.0, cargo 1.89.0.

The `mote-voice-core` crate provides the product-neutral audio decisions shared above the wire
protocol. It accepts fixed 20 ms, 16 kHz mono PCM frames; performs deterministic conversion and
resampling; detects speech; applies complete, unfinished and 90-second endpoint bounds; and
classifies caller-supplied backchannel, echo, stop and barge vocabulary.

The implementation and fixture expectations derive from Overseer revision
`2b1a19a9b6e639628367a22e16155af20df4f86a`. The crate README and NOTICE record the source files,
revision and license. Product vocabulary is supplied by the caller rather than embedded in the
shared crate.

The manifest has one direct dependency, `mote-voice-protocol`. A dependency-boundary test also
scans the implementation for operating-system audio, model, daemon, process and network imports.
Fixtures cover silence, room noise, clicks, speech opening and closing, complete and unfinished
endpoints, the 90-second split, word decisions, frame size and PCM conversion.
