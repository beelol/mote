Item: `memory_write` stores a node with embedding, `source_seq` and realm in one transaction
with no model call.

Section: docs/rfcs/v0.md#10-memory-graph

## Environment
- Date: 2026-10-09
- Host: owner's Mac, Darwin 25.6.0 (arm64)
- Toolchain: cargo 1.89.0
- Network: none (scripted Ollama server on loopback; asserted unused)

## Notes
`mem::write_node` embeds the text with a local `Embedder` (no LLM call), then inserts the node
(embedding int8[256] BLOB, realm, source_seq), its FTS row and its sqlite-vec row. Production
injects the contract's embedder (model2vec-rs potion-base-8M, quantized to int8[256]); tests use
the deterministic HashEmbedder. Test `write_makes_no_model_call_and_stores_embedding_realm_source_seq`
writes a node with source_seq 42 and asserts the embedding length is 256, realm is "personal",
source_seq is 42, and the scripted Ollama server recorded zero requests.
