# V0-03 verification

Item: `mote-paths` returns the macOS data directory and socket path and creates the directory
with mode 0700.

Section: docs/rfcs/v0.md#1-workspace

## Environment

- Date: 2026-10-08
- Host: owner's Mac, Darwin 25.6.0 (arm64)
- Toolchain: cargo 1.89.0
- Network: none

## Notes

`data_dir()` returns `~/Library/Application Support/mote` on macOS, overridable with `MOTE_HOME`
for tests. `socket_path()` is `moted.sock` inside it. `ensure_data_dir()` creates the directory
with mode 0700. The unit test asserts the paths and that the created directory's mode is 0o700.
