# UI-25: live structural interaction identity in v0

Date: 2026-10-10.
Environment: macOS 26.6.2 (25G83), arm64, Rust 1.89.0, Cargo 1.89.0, egui 0.31.0.
Base: `b07c1ec`.
Status: partial. The full backlog Verify clause remains open.

The observation harness uses the real frame decoder, ChatState reducer, MoteApp chat view,
egui renderer and outbound event queue.
Edits are entered through egui keyboard events and checked in the rendered text shapes.
No separate interaction simulator or new consumer JSON metadata is involved.

The runtime scopes a control cache by surface identity, structural child path and control type.
Matrix surfaces also include their connection epoch.
Other surfaces retain the sequence of their first committed event as their instance identity.
Replacing a named surface preserves that instance identity.
Admission still uses the current committed sequence and structural path in the side envelope.

Each complete draw records its live controls.
Controls absent from the replacement lose their edited values, text editing state and focus.
A removed Select also closes its popup.
Toggle and Action interactive responses use explicit structural IDs.
Changing between those types cannot activate the replacement with the old focus.

The regressions cover these results:

- A Field edit and keyboard focus survive a replacement with the same path and type.
  A label change does not reset the edit.
- A changed host Field value replaces the local edit.
- Changing the Field path discards the edit.
  Returning to its previous path does not restore it.
- Removing a Field or replacing it with Toggle or Select discards its edit.
  Reinsertion starts from the host value and does not receive orphaned text input.
- Removed Toggle and Select edits do not return after reinsertion.
  A removed open Select does not reopen after reinsertion.
- Changed host Toggle and Select values override local edits.
- Equal labels on separate surface instances do not share edits.
  Reconnection isolates the new Matrix epoch.
- Named and anonymous non-Matrix Field edits survive removal of an earlier Matrix message.

Before the production changes, three tests failed on stale Field resurrection or loss of an
unrelated surface edit.
Additional failing tests exposed popup resurrection and focus crossing a node type change.
The final focused run passed all nine interaction regressions.
Socket-dependent suites ran with local socket access.

This is headless v0 evidence.
Keyed rows, collection selection, duplicate-key validation and scrolling across broader
replacement surfaces require the approved versioned consumer contract.
No native focus pixels, full-catalog form behavior or table selection is claimed.

## Fix Round 1: surviving control focus

Date: 2026-10-10. Base: `ac291e4`.
The environment is unchanged.

Review found that a typed `push_id` scope did not stabilize the actual Toggle and Action
widget IDs against earlier chat allocations.
Two new ObservationHarness tests reproduced focus becoming `None` when an earlier Matrix
message disappeared.
The surviving surface identity, path and type were unchanged.

A shared renderer helper now passes the structural ID directly to egui interaction.
Named and anonymous Toggle and Action surfaces retain the same focused ID after removal
of the earlier message.
Space then emits the exact existing surface contract.
Removing the focused surface does not transfer focus to a separate equal-label surface.
The existing retype regression still prevents focus crossing control types.
