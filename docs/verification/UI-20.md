# UI-20 Vector system appearance evidence

Date: 2026-10-10.

Environment: macOS 26.6.2 (25G83), arm64, Rust 1.89.0, Cargo 1.89.0,
egui and eframe 0.31.0.

Status: verified.

## Exact theme checks

Commands:

```text
cargo test -p mote-client theme::tests -- --nocapture
cargo test -p mote-client keyboard_focus_is_red -- --nocapture
```

Output:

```text
test theme::tests::vector_uses_exact_dark_and_light_colors ... ok
test theme::tests::vector_applies_fixed_spacing_monospace_and_sharp_strokes ... ok
test theme::tests::runtime_selects_vector_for_system_light_and_dark ... ok
test theme::tests::selected_controls_keep_the_surface_fill_in_both_themes ... ok
test theme::tests::selected_text_ranges_stay_visible_and_readable_in_both_themes ... ok
test result: ok. 5 passed; 0 failed

test surface::tests::keyboard_focus_is_red_and_space_activates_the_action ... ok
test result: ok. 1 passed; 0 failed
```

The exact tests compare both Vector palettes with `matrix/themes/vector.md`. They pin the surface,
text, muted, line and accent colors. They also pin 8-point item spacing, 16-point margins, the
36-point visual control height, monospace 20, 14, 13 and 12-point type, zero corner radius,
one-point strokes, no shadow and red keyboard focus.
Native red keyboard-focus pixels are also recorded in the [UI-16 evidence](UI-16.md). The
both-theme selected-control test confirms that the focus and selection outline uses each palette's
red accent without introducing a filled box.

## Native system appearance switch

The release client ran once in `--gallery` mode with
`MOTE_HOME=/private/tmp/mote-theme-evidence.h6AGYp`. The original macOS appearance was dark.
System Events changed the system appearance to light while the same Gallery window stayed open.
The runtime redrew the window in the light Vector palette without a restart or model turn. System
Events then restored dark appearance and confirmed that the system dark flag was true.

The same Gallery region is visible in both captures. It shows the monospace scale, thin structural
rules, sharp controls, fixed spacing and red slider accent outline against each system palette.

![Native Matrix Gallery in system light appearance](assets/UI-20-native-light.png)

This verifies that Vector follows the Mac system light and dark appearance without a model turn.
