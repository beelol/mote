How it is built

One daemon in Rust, on a machine you pick.

Twenty-two screens of engineering, in the same order as the promises they deliver.

  • Repository ~/projects/mote. Board in the README under Ready for Go.
  • Every piece has a reuse document in docs/reuse and criteria on the board.
  • Planning finished 2026-10-08. No code yet.
01

Four parts, one of them holds state.

mote-cloud is the engine: lanes, memory, context, log, ledger. mote-client is the chat app. mote-ui is the renderer, alone on a Pi or inside the client. mote-talk is voice.

  • One Mac runs mote-cloud and mote-client together today. The same client reaches a server later. The Pi stores nothing.
  • Unix socket locally. A WebSocket gateway with a Noise handshake for everything else.
  • Closing a client never ends a thread.
02

Talk lane: a local model first.

Ollama runs qwen3:4b on the Mac. Haiku through your Claude subscription when the Mac cannot.

  • Warm 1B to 4B models answer in 22 to 90 ms to first token on Apple Silicon.
  • The memory gate loads a model only when free memory is 1.25 times its size.
  • The Pi cannot hit 300 ms with prefill, so it stays a client of the Mac for talk.
03

Attention: is this for me?

Voice activity, a speaker embedding and a 0.6B scorer over the last few seconds of transcript produce one calibrated sureness.

  • No open model for device-directed speech exists. The Amazon and Apple pattern is ported.
  • Bands default to answer at 75, ask between 40 and 75, silent below. All settings.
  • Every verdict is logged with its reason.
04

Router: a trained head, not a tiny LLM.

Small embeddings plus a logistic head decide talk, think or work in 2 to 4 ms. Abstentions go to the resident talk model as judge.

  • Sub-2B models score under 50% zero-shot on intent benchmarks. A trained head on small embeddings reaches about 86% from 8 examples per class.
  • One fail-closed parser is the only producer of a route. Malformed never means talk.
  • Rules read only structural signals such as a code fence or a diff header.
05

Think lane: Claude Code as a child process.

One claude -p per turn, streaming partial messages, resumed per thread, under your login.

  • Never with the bare flag: bare mode skips the keychain login and needs an API key.
  • Tools come from one moted mcp server: memory, delegate, Slack read. GitHub through an allowlisted gh.
  • An expired login is classified as auth and becomes a sign-in card. The turn waits.
06

Work lane: your Mac when it is on, the device when it is not.

With the Mac up, mote starts an Overseer run over its socket and mirrors every event. With the Mac off, the device plans what it can do alone and queues the rest.

  • A persistence loop retries, lines up alternatives, and waits for you only when truly blocked.
  • Overseer owns worktrees, accounts and diffs. mote owns the thread and the cards.
  • Both of these need criteria. They are new as of today.
07

Context layer: reach everything, efficiently.

Connectors sync Slack, mail, calendar, files, code and the web into one local index. Retrieval and consumption serve every lane under a budget. A coverage map says what mote can and cannot see.

  • Knowing what it does not know is a product promise, so the coverage map is first class.
  • The storage engine is open: SQLite with graph tables, or an embedded graph database. A spike decides.
  • The RFC is being written now.
08

Memory: a temporal graph.

Entities, events, procedures and summaries as nodes. Edges carry valid-from, valid-to, created and expired. Every row points at the event that caused it.

  • Writes are one transaction and zero model calls. Local embeddings from a 30 MB model.
  • Retrieval fuses vectors, full text, a two-hop walk and recency under a per-lane token budget.
  • None of the ten memory libraries in the post can be embedded in Rust. Ideas ported from Graphiti and Zep.
09

Context packs and the ledger.

Each call gets an ordered pack: system, profile, tools, memory, snapshots, summary, working set, turn. Each part carries a hash and a token estimate. The ledger row points at the pack.

  • Stable parts first, volatile parts last, so the prompt cache stays warm.
  • Usage comes from the claude -p result line and Ollama counters. Costs are deltas, since resume reports cumulative totals.
  • Column names follow the OpenTelemetry GenAI conventions.
10

Event log: one table, one cursor.

Append-only SQLite in WAL mode. Clients replay from a cursor and never see an event twice.

  • AUTOINCREMENT is required: pruning plus plain rowids can move a cursor backwards.
  • Lagging subscribers get a resync signal and resume from the durable log.
  • Targets: append under 1 ms, replay of 1,000 under 20 ms, 5,000 events kept per scope.
11

Screens: a small language to pixels.

Models emit a validated tree today and a small language later. Flexbox plus anchors, one theme per screen, typed bindings. A renderer the daemon owns turns it into animated pixels.

  • Compact JSON costs 512 tokens for three fixtures. The language 338.
  • The model emits whole surfaces. The renderer diffs and animates the difference.
  • Targets: Mac window, Pi touchscreen over DRM, PNG for tests, terminal through a pixel protocol.
12

Chat surface: sent, delivered, read, typing.

The texting feel from dots stays. Every message carries delivery and read state. Characters are a setting.

  • Built on the same event log: each state change is an event with a cursor.
  • Characters change voice, tone and name. They never change what mote may do.
  • Needs criteria. New as of today.
13

Always-on: supervised, gated.

launchd on the Mac and a systemd user unit on the Pi keep the daemon up. Watchers wake the router. Every outward action waits in an approvals table.

  • Slack through Socket Mode with a bot token you provide. GitHub by polling notifications.
  • Approve, Edit or Deny on a card. Approvals expire after 24 hours. Watchers can never approve.
  • Cron through a small scheduler over a schedules table.
14

Hardware: a Pi 5 as a client.

Pi 5 with 8 GB and the official 7 inch touch display, no desktop, DRM and evdev straight from Rust. About $276 before audio.

  • Cross-compiled from the Mac with cargo-zigbuild.
  • The gateway uses Overseer's Noise IK handshake. A relay sees only envelopes, never plaintext.
  • Echo cancellation in hardware or a pure-Rust AEC3 port.
15

Browser: a real one, driven by the agent.

Two modes. Cloud: a headless browser on the machine you picked as the cloud, with only the sessions you gave it. Local: your own signed-in browser on the Mac, used to make calls and reach sites as you.

  • Pages are read as accessibility trees first and pixels second. A task moves between modes when the Mac comes online.
  • Form submits, purchases and sends go through the same approval gate as every outward action.
  • Sign-ins stay the owner's. The agent never creates accounts or types credentials.
16

Shared crates: nine, out of Overseer.

redact, paths, usage, eventlog, ipc, harness, accounts, localmodel, gateway. mote consumes them now. Overseer migrates in 11 proved steps.

  • Most of the source is pure functions over JSON values. The cuts are small.
  • Extraction order follows coupling. mote's first criteria need four crates.
  • MIT, with derivation notices per crate.
17

Testing: zero paid turns.

A scripted server speaks the Ollama wire format. A fake claude speaks stream-json. A fake Overseer answers the socket. Every lane runs deterministically.

  • Golden snapshots for parsers, property tests for fail-closed parsing, recorded transcripts replayed.
  • Network isolation is enforced by a loopback-only guard, not assumed.
  • Live checks run only behind a flag and are recorded with command, output and date.
18

Visibility: click any stage.

A pipeline view inside the client, drawn by mote-ui. Each stage shows its live events, its config as controls, its numbers against budget, and every request it made.

  • Swap the think harness or a lane's model hot. The daemon validates fail-closed, applies next turn, and can revert from the event log.
  • Metrics are computed in Rust in the daemon from a ring buffer and the ledger. The view updates within one frame.
  • Opening the view adds no measurable latency to the lane it inspects.
19

Security: nothing leaks, nothing acts alone.

Owner-only data directory. Redaction before storage. No secret ever enters a model call. Memory changes only through one tool, visibly and reversibly.

  • Subscription logins stay in their harness's keychain. mote never copies them.
  • Outward actions need approval in the window.
  • The relay trust boundary is written down before any relay exists.
Where it stands

Planned, not yet built.

The board holds about 250 criteria, each with a Verify clause. A driver can start on the daemon core and the four core crates today.

  • Waiting on the owner: wire format, extraction order, memory model, a chat model to pull, a Slack token.
  • New today and without criteria: persistence loop, computer-off mode, the chat surface, characters, the context layer, browser use.
  • Everything is uncommitted in ~/projects/mote.
